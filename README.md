# APP BLCOKER(macOS)

This is my first app, Multi-App-Blocker.
So, this an application that only runs only on macOS which blocks apps according to the time schedule set by the user. I made this app because I saw a lot of children, including myself spending a lot of time on their laptops just for rubbish things. So, I took the initiative and built this APP BLOCKER that can also act as a children's lock in many parents' life.

## How To Use

It is very simple to use App Blocker. When you would open it, you would see a normal interface with a button ***ADD AN APP TO BLOCK***. When you would click on the button, you would see an interface with a dropdown to select the application, the placeholders for starting and ending time, the dropdown for schedule type and three options- ***Add Another Schedule***, ***Save Schedule***, ***Cancel***. When you would click on Add Another Schedule button, you would see a similar interface as you got after clicking Add An App to Block button, but the difference would be that this interface would already have the app selected and you cannot change that. After completing the details of the schedule you have to click on Save Schedule button to save all your schedules. After saving the schedules, there would be 3 dots, those would be- ***Delete*** for deleting the schedule. ***Disable*** which disables the schedule which you can later enable. ***Edit*** which lets you edit the schedule even after it is saved. So, thid is how you can use the App Blocker efficiently to block the apps you select.
